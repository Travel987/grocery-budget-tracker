# Grocery Budget Tracker

A React application that helps users manage grocery spending and stay within budget.

## Features
- Set a grocery budget
- Add grocery items with prices
- Delete items from the list
- Track total spending
- View remaining balance

## Technologies Used
- React
- JavaScript
- CSS
- React Router

## Purpose
This project was built as part of the LaunchCode curriculum to demonstrate core React concepts including state management, component structure, and routing.
